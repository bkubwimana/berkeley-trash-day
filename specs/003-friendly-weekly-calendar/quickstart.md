# Quickstart Validation: Friendly Weekly Calendar

1. Run `npm test`, `npm run check`, and both npm audits.
2. Start `npm run dev`.
3. Confirm the default page is light and the selected cart/calendar logo replaces BT.
4. Confirm road segments visibly show 2100, 2200, 2300, and 2400 without repeating “block.”
5. Confirm the seven-day calendar changes with range selection and contains no events for empty local data.
6. Use a fixture to verify multiple streams may share one day and retain developing/consensus status.
7. At 320 CSS pixels, confirm the page has no horizontal overflow and all four address targets remain at least 44 pixels tall.
8. Confirm OpenStreetMap attribution is in the footer and absent from the corridor.
9. Confirm production schedule data remains empty unless residents have made real reports.
